# Worm Agents

Landing de [worm-agents.com](https://worm-agents.com): la familia de agentes de IA open source (WorkWorm, LoveWorm, InvestWorm, SocialWorm). Por ahora los agentes corren en Windows con [Claude Code](https://claude.com/claude-code) y la suscripción de Claude de cada usuario.

Es un sitio estatico: `index.html` y `favicon.svg`, sin build. Para verlo, abri `index.html` en el navegador.
